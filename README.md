## 🚀 Быстрый старт

### Установка шаблона в Blogger

1. Скачайте `blogger-template/template.xml`
2. Blogger → Тема → Изменить HTML → Удалить всё → Вставить код → Сохранить
3. Настройки → Сообщения → Максимальное количество сообщений = **50**
