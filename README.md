# gallery.obrazslov.ru — Фотоархив НКО

Этот репозиторий содержит шаблоны, скрипты и конфигурации для сайта-витрины НКО `gallery.obrazslov.ru`.

## Структура
- `/blogger-template/` — XML-шаблон для Blogger
- `/scripts/` — скрипты для автоматической публикации изображений (IGalleryExporter)
- `/config/` — конфигурации (настройки тематических страниц)

## Использование
Сайт работает на платформе Blogger с кастомным доменом. Изображения загружаются автоматически через IGalleryExporter из САН и Пантеона.
